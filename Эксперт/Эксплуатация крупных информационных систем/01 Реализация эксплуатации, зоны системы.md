## Зоны системы  

**Распредение на зоны**  
При реализации эксплуатации крупной информационной сиистемы выделяются:  
  - рабочая зона информационной системы;
  - подготовительная зона информационной системы;
  - зона естирования продукта;
  - зона разработки продукта.

**Настройки для зон.**  
Рабочие серверы информационной системы:  
  - запрещена отладка;
  - пользовательские данные;
  - обновление только с использованием чек-листов по заранее согласованному плану;
  - настроен мониторинг;
  - доступ только у групп эксплуатации.

Подготовительные серверы информационной системы:  
  - разрешена отладка;
  - пользовательские данные;
  - все изменения фиксируются;
  - контроль обновления и работы на новых версиях продукта, контроль потребления ресурсов на новых версиях;
  - настроен мониторинг;
  - доступ только у группы эксплуатации.

Сервисы тестирования:
  - рахрешена отладка;
  - тестовые данные;
  - изменения вносятся постоянно;
  - натсроен мониторинг;
  - доступ у разработчиков.

Серверы разработки продукта:  
  - разрешена отладка;
  - тестовые данные;
  - изменения вносятся постоянно;
  - мониторинг может отсутствовать;
  - доуступ у разработчиков.

**Организация внесения изменений на подготовительной и рабочей площадках.**  

Вводиться правило: все изменеия в рабочую систему вносятся только через подготовительную площадку информационной системы.  
Сначала изменения попадают на подготовительный стенд, потом на рабочий.  
Существут только одно исключение из данного правила, изменения в рабочую систему могут вносится минуя подготовительный стенд, в экстренных ситуациях.  
По окончанию аварийных работ в ночное время, стенд должен быть синхронизирован с рабочей зоной, чтобы устранить разницу в внесенных изменениях.  

Состояние подготовительного стенда может меняться следующими способами:
  - развертывание бекапов;
  - развертывание копий машин;
  - с подготовкой чек-листов;
  - не большие работы без подготовки чек-листов, но с обязательной записью в журнале регистрации проведенных работ.

Состояние рабочего стенда может меняться следующими способами:  
  - по чек-листам;
  - в случае аварийных работ при недоступности рабочей системы;
  - перенос небольших изменений с подготовительного стенда с записью в журнале регистрации проведенных работ.

Журнал регистрации проведенных работ - специальный документ который ведут все участники эксплуатации рабочей и подготовительных систем. В журнал попадают все записи о изменении в очень сжатой форме. Цель журнала - в случае аварии быстро определить, кто и когда вносил изменения.  

  
Пример записи в журнале регистрации проведенных работ:  
2020-01-01 Администратор1 <admin_petr@1c.ru> +79871234567  
* server1c-1  
– поправил com connector, выполнив команду из rdp сеанса C:\1C\current\regsvr32 comcntr.dll
