## Настройка оборудования Perfomance monitor

Параметры для натсройки ОС Windows:
  1. Memory (Память) - Commited bytes in use (% использования выделенной памяти) - счетчик показывает процент относительно суммы размера оперативной памяти и файла подкачки, а не только использование оперативной памяти. Не должен превышать рамера оперативной памяти
  2. Memory (Память) - Available Mbytes (Доступно, Мбайт) - счетчик позывает объем свободной физической оперативной памяти. Приближение к нулю свидельствует о недостатек оператвной памяти.
  3. Processor [_Total] (Процессор [_Total]) - % Processor Time (% загрузки процессора) - рекомендованный максиму не более 70% в течении длительного времени.
  4. System (Система) - Processor Queue Length (Очередь к процессорам) - рекомендованный максимум - не боле 2* на количество ядер процессоров в течении длительного времени.
  5. Phisical Disk (Физический диск) - Avg. Disk Queue Length (Средяня длина очереди к дискам) - обязательно для системных дисков отдельно, для диска с базой отдельно, для диска с жерналом транзакций (если такой есть) отдельно. Рекомендованный максимум не более 2 * количество дисков, работающих параллельно.
  6. Logical Disk - % Free Space - показатель наличия свободного места на диске и динамики его изменения.
  7. Network Interface (Сетевой интерфейс) - Bytes Total/sec (всего байт/с). Рекомендованный максимум не более 65% от пропускной способности адаптера в течении длительного времени.

Настройка для СУБД MS SQL Server:
  1. SQLServer:Buffer Manager | Page life expectancy (PLE) - Показывает, сколько секунд страница данных находится в буферном кэше (оперативной памяти) без обращений. **Высокое PLE (хорошо)**: Страницы живут в памяти долго (например, > 300-600 секунд). Данные переиспользуются, повторных чтений с диска мало. Низкое PLE (плохо): Значение падает (например, < 100-200 секунд или постоянно "проседает" до минимума). Это означает, что страницы вытесняются из памяти очень быстро, чтобы освободить место для новых. Это прямой признак дефицита памяти (memory pressure) для SQL Server
